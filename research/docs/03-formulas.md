# 全部计算公式

## 符号与日历

- i：800股清单中的代码，代码按字典序固定排序。
- t：冻结XNYS日历的交易日序号，1990-01-02为0；t−k指k个交易日前，非自然日。
- Cᵢ,ₜ：供应商CSV的Close；Aᵢ,ₜ：Adj Close；Oᵢ,ₜ：供应商Open；Vᵢ,ₜ：Volume。
- n：流动性窗口，5…200；m：动量分母距今间隔，20…300；s：排除期，新网格固定5。
- K：整批持有数量，1…5；c：单边费用率，例如10基点=10/10,000=0.001。
- Wₜ：美元名义净值；所有账户起始为1。允许零碎数学单位，现金收益为0。

CSV里的收益、波动、回撤和投资比例都按小数保存，0.4773表示47.73%，−0.7537表示−75.37%；不是已经乘100的数字。

## 1. 连续253个有效交易日

```math
q_{i,t}=\mathbf1\{C_{i,t}, A_{i,t}, V_{i,t}\text{ 均为有限正数}\}
```

```math
E_{i,t}=\prod_{j=0}^{252}q_{i,t-j}
```

E=1才有资格。不能先删掉停牌或缺失日期，再把253行当作253个连续XNYS交易日；不能用前值填充通过资格。开盘价缺失本身不改变收盘信号资格，成交时单独处理。

## 2. 流动性金额代理

```math
D_{i,t}=C_{i,t}V_{i,t},\qquad L_{i,t}(n)=\frac1n\sum_{j=0}^{n-1}D_{i,t-j}
```

窗口含信号当天。在所有E=1的股票中按L从高到低取最多500只，记为Uₜ(n)。若资格股票不足500只，使用实际数量。完全相同的L按代码升序。

这是跨股票绝对规模排序，不是本股成交金额变化率，不要求正在增长。C使用供应商字段，未重建历史原始名义价格；真实原始成交金额与本代理的区别见理论和验证文档。

程序用前缀和加速：Pᵢ,ₖ=Σⱼ<ₖDᵢ,ⱼ，L=(Pᵢ,ₜ₊₁−Pᵢ,ₜ₋ₙ₊₁)/n。无效行只在前缀和存储中置0；资格检查仍禁止它们进入当前有效窗口。

## 3. 新动量与原始12−1

```math
M_{i,t}(m,s)=\frac{A_{i,t-s}}{A_{i,t-m}}-1
```

本轮s=5、m=20…300，测量t−m到t−5的累计涨幅，长度为m−5个交易间隔。最近5个交易间隔不进入动量分子分母收益区间；当天收盘仍进入流动性和资格检查。

在Uₜ(n)内部按M降序选前K只；M并列按代码升序。不要求M>0。分母或分子不合法时只从候选池内部排除，不从流动性500名以外补充。m>252时只额外要求历史端点合法，没有把资格窗口改为连续m+1天。

原始对照为L(200)及M(252,21)，本轮分别测试同样5日交易规则下持有2只和5只；没有用不同持股上限的20只账户冒充可比控制。

GPU对所有K共享有序Top5，并对任意前1…5名内部并列或边界并列执行稳定排序。实现会在有序Top5不足5个有效分数时将整批标为无效；本研究不声称这一边界处理等同于逐K补足任意不足数量的泛化实现。具体代码见 `../code/gpu_core.py`。

## 4. 复权开盘价与单笔收益

```math
\widetilde O_{i,t}=O_{i,t}\frac{A_{i,t}}{C_{i,t}}
```

信号t收盘形成，买入日e=t+1，目标卖出日x=e+5=t+6。

```math
R^{gross}_{i}=\frac{\widetilde O_{i,x}}{\widetilde O_{i,e}}-1
```

```math
R^{net}_{i}=\frac{\widetilde O_{i,x}}{\widetilde O_{i,e}}\frac{1-c}{1+c}-1
```

买入分母1+c是为费用预留现金。该式是单笔含买卖费用的回报，不可把它的简单算术平均直接当成多年账户CAGR。

这里买的是复权价格指数单位，近似包含分红拆股的总回报；没有恢复真实券商股数、现金股息到账日、税扣及全部公司行动。

## 5. 等权预算与自融资账户

整批账户可用现金为B，每只预算b=B/K；如开盘有效：

```math
u_i=\frac{b}{(1+c)\widetilde O_{i,e}}
```

卖出后入账：

```math
\Delta Cash_i=u_i\widetilde O_{i,x}(1-c)
```

未成交的份额b留现金，不摊给其他股票。买入权重相等，持有期间不再平衡；卖出全部到期仓位后再买下一批。若某个旧仓无法卖出，整批账户等待，不借款开替代仓。

每日轮换账户初始有5份现金，各0.2；每份独立复利，一天轮换其中一份、每份只买1只。各份净值随收益漂移，并非每天强制调回20%，也没有把每天满仓的5日收益简单叠加。

逐日净值：

```math
W_t=Cash_t+\sum_{i\in holdings_t}u_i\widehat A_{i,t}
```

有效收盘用A估值；缺失、非正或零成交量行沿用该持仓此前可观测标记，入场后尚无有效收盘时以成交开盘价作为初始标记。研究终点采用实际开盘卖出后的现金；所有已发表主账户终点均已清仓。

## 6. 绩效与风险

总收益：

```math
TR=\frac{W_T}{W_0}-1
```

按实际日历日年长计算年化，而非用交易数除5估算：

```math
Y=\frac{Date_T-Date_0}{365.25},\qquad CAGR=\left(\frac{W_T}{W_0}\right)^{1/Y}-1
```

日收益、历史高点、逐日回撤及最大回撤：

```math
r_t=\frac{W_t}{W_{t-1}}-1,\quad H_t=\max_{u\le t}W_u,\quad DD_t=\frac{W_t}{H_t}-1,\quad MDD=\min_t DD_t
```

年化波动与夏普，日样本标准差采用ddof=1，无风险利率设0：

```math
\sigma_{ann}=sd(r_t)\sqrt{252},\qquad Sharpe=\frac{mean(r_t)\,252}{\sigma_{ann}}
```

年度收益以该年末净值相对上年末净值计算；起始年相对初始1。净值表中后段账户的2015-12-31为起始基点，其2015年0不是额外一整年的交易结果。

年化超额百分点=CAGR策略×100−CAGR基准×100；不是回归alpha。交易胜率=扣费单笔往返收益>0的笔数/已完成往返笔数。投资比例=1−现金/W；程序要求现金不为负、投资比例≤1、仓位数量≤K或≤5。
